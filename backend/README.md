# Backend

This directory is reserved for the Spring Boot API and PostgreSQL persistence
work that begins in Sprint 5.

Sprint 1 adds no Java source, Maven project, API endpoint, database migration,
Docker Compose service, authentication, or enterprise integration.

The future base package is `com.qnity.deploymentassistant`, and the dependency
rules are documented in
[`docs/development-standards.md`](../docs/development-standards.md).
