# PowerShell assistant

This directory is reserved for Version 1 of the local technician assistant.
Implementation begins in Sprint 2.

Sprint 1 adds no device-changing commands, input handling, application detection,
logs, summaries, network calls, or scheduled tasks. The planned assistant must
support non-destructive simulation and `-WhatIf` before approved device settings
are applied.

The original concept README is preserved under
[`docs/reference/original-version-1-readme.md`](../docs/reference/original-version-1-readme.md)
for traceability. Its implementation claims are not current project status.
